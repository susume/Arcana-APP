# Quiet Atelier imagery

Updated 2026-10-02 to match the parchment, forest, sage, and brass site theme.

## Photography

`reading-table.png` and `reflection-journal.png` were created with the built-in
image generation tool. The matching `*-prompt.txt` files contain the complete
generation prompts. Both are square 1254px sources. Their `.webp` exports are the
web versions: 345KB and 302KB, respectively, instead of approximately 2.6MB
per PNG. Images depict a warm daylight reading table and a tactile journal.

## Illustrations

The SVG files are original code-native decorative illustrations in the same
palette: spread selection, physical draw, photographing a spread, reading
insight, a physical card, and a digital card grid. They contain no product copy.

## Branding

The user-supplied horizontal and stacked logos are preserved as original PNGs in
`assets/brand/`. The horizontal WebP is a resized lossless web export with alpha;
the icon is a small PNG export of the stacked source. No artwork was regenerated
or recolored. CSS frames only remove transparent outer whitespace from headers.
Homepage branding retains an accessible heading; product logo buttons retain
their Arcana home label and keyboard focus behavior.

All decorative homepage image references now point to this set. Actual Tarot
card artwork in the identification/review flows remains unchanged so readers can
recognize their physical cards. Runtime reading/share canvases have their own
separate styling.

## Benefit campaign follow-up

`personal-insight.png` and `reading-keepsake.png` were generated with the built-in
image tool for the shorter three-benefit sales pitch. Exact prompts are saved in
`personal-insight-prompt.txt` and `reading-keepsake-prompt.txt`. Both are 1448×1086
sources; 1000px WebP exports load on the homepage at approximately 182KB and
167KB. The journal card reuses `reflection-journal.webp`.

The orbital cards and keepsake print are illustrative marketing scenes, not
screenshots or replicas of the app's generated infographic. The keepsake contains
symbolic artwork with no invented reading text. Actual exports continue to use
the existing reading/share renderer. No uploaded brand artwork was changed.
